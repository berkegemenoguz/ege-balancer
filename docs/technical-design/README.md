# Technical design

The design document this project was built to, and the notes for bringing it up to date now that
the twelve day plan is finished. Every document here is a PDF, named
`<document>-<version>-<language>.pdf`.

| File | What it is |
| --- | --- |
| [technical-design-v1.6-tr.pdf](technical-design-v1.6-tr.pdf) | The design document as written before implementation started. The source of truth for scope. |
| [revision-notes-v1.7-tr.pdf](revision-notes-v1.7-tr.pdf) | Section by section edits that bring the document in line with what was built, with the replacement text ready to paste into it. |
| [revision-notes-v1.7-en.pdf](revision-notes-v1.7-en.pdf) | The same revisions in English, for a reader who does not read Turkish or for an English edition of the document. |

The design document is in Turkish, so the Turkish revision notes are the operative ones: their
replacement text goes straight into it. The English notes describe the same changes.

The reasoning behind each change lives in [design deviations](../design-deviations.md); the
revision notes reference it entry by entry.
