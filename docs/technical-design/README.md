# Technical design

The design of the project as a paper, and the original design it grew from. Everything here is
Markdown, named `<document>-<version>-<language>.md`.

| File | What it is |
| --- | --- |
| [technical-design-v1.8-en.md](technical-design-v1.8-en.md) | **The current design.** The system as built and its evaluation, with a record in Appendix B of every place it departs from v1.6 and why. |
| [technical-design-v1.8-tr.md](technical-design-v1.8-tr.md) | The same document in Turkish. |
| [technical-design-v1.6-tr.md](technical-design-v1.6-tr.md) | The original design and twelve day plan, written before implementation started. Kept unchanged, for history. |

The two editions of v1.8 carry the same content; a change to one is made to the other in the same
commit. The v1.7 revision notes and the separate list of design deviations were folded into v1.8
and removed; both remain in the repository's history.
